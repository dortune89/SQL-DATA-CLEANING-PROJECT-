# SQL Data Cleaning: Layoffs Dataset

MySQL data cleaning project using staging tables to protect the raw data.

## What I did
- Found duplicates with ROW_NUMBER() and a CTE, then removed them
- Standardized text with TRIM, including country names
- Converted text dates to the DATE data type
- Reviewed blank and null values
- Removed rows missing both layoff measures
- Dropped the helper column after cleaning

## Skills
SQL, MySQL, CTEs, window functions, data cleaning, data standardization
